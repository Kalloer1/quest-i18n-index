## 三、风险与对策

| 风险 | 对策 |
|---|---|
| 夸克 cookie 过期（CI 无浏览器） | 上传/建链失败超阈值 → 工作流自动停并通知你换 secret；已传进度不丢 |
| 分享链接创建触发风控 | 只在「建链」这一步分批限速；上传本身全速 |
| 跨平台归并误判（494 组同名） | 只自动归并「同名 + slug 相似度 ≥0.9」，歧义进 `needs-review` 由你确认 |
| 内嵌试点失败（确实无翻译系统） | 2.2 处停下汇报，不盲目铺开 417 |
| 主机不稳定 | 每台都有「连续 3 批无进展自停」保险；本机 `publish` 随时收批，损失最多一批 |
| GitHub 直链滥用 | Phase 4.4 的全局开关是兜底；另加 IP+groupId 24h 去重 |
| KV 里的 LLM Key 泄露 | Key 字段打码显示；Worker 只把 Key 下发给翻译机（env），自身请求不带 Key；泄露时管理页一键换 Key 即可 |
