# 共享上下文（两位设计师都必须先读这份）

## 产品是什么

**Minecraft Java 版整合包「任务书」汉化站。**

玩家的真实路径：在整合包里玩，任务书是英文的看不懂 →
来站里找到**这个整合包** → 下载对应版本的任务书汉化 → 按安装说明放进游戏 → 任务界面变中文。

**注意：本站在做的是「任务书」汉化，不是模组汉化。** 模组本身早就由 CFPA 团队汉化完了。

## 三种状态（这是本产品信息架构的核心）

每个整合包只有三种状态，页面**必须能区分且都不能静默隐藏**：

| 状态 | 含义 | 玩家能做什么 |
|---|---|---|
| **可下载** | 本站已产出该整合包的任务书汉化 | 下载 |
| **自带中文** | 整合包自己就带中文（社区翻译随包分发） | 无能为力，但要**明确告知**，避免玩家白找 |
| **待翻译** | 有英文源、本站还没翻译 | 提交请求 / 看进度 |

**为什么「自带中文」必须显式展示**：实测头部热门整合包（ATM 系列、FTB 系列）大多已自带中文。
若不标注，玩家会以为本站漏了。

## 真实数据

`design/demo-data.json` —— **22 条真实整合包数据**，字段：
`slug / title / description / iconUrl / screenshots[] / downloads / gameVersions[] / loaders[] / authors[] / categories[] / siteStatus（待翻译|自带中文）/ enFiles / zhFiles / layout / updated`

15 条「待翻译」、7 条「自带中文」。**设计稿请用真数据，不要编造占位文本**（图片用真实 URL）。

## 硬约束

1. **许可（法律要求，不可省略）**：本站产出基于 CFPA 团队与模组作者的译名，
   许可为 **CC BY-NC-SA 4.0**。站内**必须有**署名与许可声明（CFPA 团队 + 相关模组作者），
   且站点为**非商业**——不得出现广告位、付费、赞助墙的设计。
2. **安装说明必须显眼**：产物是一组文件/目录（不是资源包 zip），
   放错位置玩家会以为汉化没生效——这是本站投诉的第一大来源。
3. **移动端必须适配**：参考项目的教训是「手机端 8 个显示问题返工一次」
   （列表溢出、按钮换行、筛选条溢出、触控目标过小）。移动端不是事后补的。
4. **无障碍基线**：AA 对比度、可见焦点环、键盘可达、触控目标 ≥44px、语义化 HTML。

## 交付要求（两人相同）

- 产出**自包含 HTML**：内联 CSS（可用极少量内联 JS），**双击即可在浏览器打开**，不依赖构建、不依赖 CDN
- 至少覆盖四个视图：**列表页 / 详情页 / 安装说明 / 关于与许可**
- 界面语言：**简体中文**
- 放两个断点：桌面（≥1200px）与移动（≤480px），在同一文件里用媒体查询实现
- 钉住设计决策的理由：每个关键决策用**注释或单独的设计说明段**写清「为什么这么选」
