# 已知陷阱

> 每条都是**实测踩到并验证过**的，不抄书本、不猜。新踩到的往后面追加。

## 2026-10-17

| # | 现象 | 根因 | 规避 |
|---|---|---|---|
| 1 | EN 语言文件解析出 **0 条**，同一份代码解析 ZH 却正常（190 条） | **`\r\n` 行尾**。JS 正则里 `.` **不匹配 `\r`**，而 `$` 只匹配真正的输入末尾。所以 `^\s*([\w.]+)\s*:\s*(.*)$` 对 `key: "v"\r` **一律不匹配** | 解析前先 `text.replace(/\r\n/g, '\n')`；或避免用 `.` + `$` 收尾。**实测 EN 是 CRLF、ZH 是 LF，两者可能不同** |
| 2 | `Range: bytes=-65536`（后缀写法）返回 **501**，被误判成「CDN 不支持 Range」 | 后缀写法不受支持 | 必须用起止写法 `bytes=<start>-<end>`（返回 206） |
| 3 | `edge.forgecdn.net` 上发 Range 返回 **404** | 它是重定向层，只支持 HEAD/GET 整包；Range 由最终的 `mediafilez.forgecdn.net` 处理 | 先 HEAD 跟随重定向拿最终地址，再对其发 Range |
| 4 | CurseForge API 搜不到 FTB Quests 本体 | FTB 团队主发 CurseForge 自有作者页，`mods/search?searchFilter=ftb` 搜不到 | 不要靠 Modrinth/CF 的依赖列表或搜索判断"这个包有没有任务书"——**只读 zip 中央目录**才是可靠判据（见 ADR-0001） |
| 5 | 写扫描脚本时 `awk` 里用 JS 语法 `($4/1048576).toFixed(0)` 报 syntax error | awk 不是 JS | awk 里用 `sprintf` 或 `$4/1048576` 直接打印 |
