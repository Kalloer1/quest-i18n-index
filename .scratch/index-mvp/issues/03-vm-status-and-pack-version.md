# 03: VM 状态与适用版本入库

**What to build:**

让页面能告诉玩家「这家的汉化还在维护吗、适配哪个整合包版本」，而不是甩一个可能是 2019 年停维的链接。

ADR-0006 的原文约束：VM 官网条目里多数已停止维护，「把停维补丁当答案等于没帮忙」。
社区约定 #45 还指出译文与整合包版本强绑定，跨版本用会坏。

现状：仓库里的 `research/vm-packs.json` 有 71 条，但每条只有 `vmSlug`/`title`/`originalName`/`icon`
四个字段，没有状态、没有版本。仓库里也**没有生成这份文件的脚本**——它是一次性产物。
VM 官网是 SPA，数据在前端 bundle 里，条目字段包含 `status:{type}` 与 `versions:{loader, mc, pack}`。

需要新写一个可重跑的抓取器，把状态与版本补进去。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新增可重跑的抓取器，从 VM 官网取得每个条目的 status、loader、mc、pack 版本
- [ ] 抓取器对 71 条与调研笔记中记录的 58 条之差异给出解释（去重口径或数据变更），不静默取其一
- [ ] 每条记录带来源 URL 与抓取时间戳
- [ ] status 取值限定为 stopped / maintaining / translating，出现未知值时保留原值并标记，不丢弃
- [ ] 抓取失败或字段缺失时明确标记为缺失，不用空字符串或猜测值填充
- [ ] 产出可通过测试验证：给定一份固化的 HTML/JS 样本，解析结果稳定
