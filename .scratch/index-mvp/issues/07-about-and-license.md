# 07: 关于页：来源、许可、非商业、验证判据

**What to build:**

一个能打开的页面，让玩家和后来的人看清这个站凭什么可信、法律上站得住、以及它什么时候会被判定为不该继续做。

四块内容：

1. **数据来源**：CurseForge、Modrinth、VM 汉化组官网，各自的抓取方式与时间。
2. **许可状态**：本站索引只放链接、不重分发任何第三方内容，因此不继承 CFPA 的 CC BY-NC-SA 约束；
   但若将来开始分发译文，则必须署名 CFPA 团队与相关模组作者。这个区分要写清楚，
   否则将来的人会误以为已经合规或误以为永远不用管。
3. **非商业声明**：无广告、无付费、无赞助墙。ADR-0004 规定若将来商业化必须重做术语来源。
4. **验证判据**：ADR-0006 的结论——两个月真实流量无起色则得出「不该做」。要把判据写成可对照的形式，
   而不是一句口号。
