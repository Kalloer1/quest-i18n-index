# 06: 详情：状态 + 汉化在哪 + 适用版本 + 不能混装

**What to build:**

玩家点开一个整合包，看到四件事：任务书现在是什么状态、汉化在哪一家（带该家的维护状态与适配的整合包版本）、
装了之后和别家汉化能不能共存、以及每条结论的来源与抓取时间。

这是 ADR-0006 里「索引必须带的三样东西」的落点：状态、适用版本、不能混装警告。

关键约束：社区约定 #46 指出不同来源的汉化**不能同时装**。这意味着对玩家来说这是一道排他选择，
页面必须把这个代价说清楚，而不是并列堆几个下载链接。

另一条约束：本站产出与社区已有必须**视觉强分栏**。本轮本站产出恒为 0，
所以分栏落在「社区已有」一侧，但结构必须留出来，否则将来加产出时会退化成混排。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 详情页显示六态之一，且该状态与列表页、查询结果一致
- [ ] 每个外部汉化来源显示：提供方、维护状态（stopped/maintaining/translating）、适配的整合包版本、来源链接
- [ ] 停维来源被显式标注，不与维护中的来源同等呈现
- [ ] 不能混装警告显式可见，不折叠、不藏进 tooltip
- [ ] 「本站产出」与「社区已有」分栏存在且视觉可区分；本站为空时有明确空状态文案
- [ ] 每条外部结论可点击跳转原始来源，并显示抓取时间
- [ ] 内嵌布局包显示为「内嵌不可做」，并说明原因（该版本无翻译系统），不是简单一句不可用
- [ ] 桌面与移动两个断点均可用，无横向溢出，触控目标 ≥44px
