# 05: 查询：输入整合包名 → 命中

**What to build:**

玩家打开页面，输入整合包名（中英文皆可、可残缺、可带大小写差异），就能看到这个包的任务书状态；
输入不存在的名字时看到明确的空状态而不是空白页。

这是「查」这条竖切第一次在屏幕上可见。完成后应能用真实数据演示：输入「FTB StoneBlock 4」
得到自带中文与社区汉化状态；输入「stoneblock」这类残缺词也能命中；输入一个内嵌布局包
得到「内嵌不可做」而不是「查无此包」。

技术形态：自包含静态 HTML，内联 CSS，零构建零 CDN，双击可开。数据来自构建器产出的 JSON。
桌面 ≥1200px 与移动 ≤480px 两个断点在同一文件内用媒体查询实现。

**Blocked by:** 02, 03, 04

**Status:** ready-for-agent

- [ ] 输入完整包名能命中，结果含标题、图标、六态之一
- [ ] 输入残缺词或大小写不一致能命中
- [ ] 输入不存在的名字有明确空状态文案，不是空白页
- [ ] 六态中每一种都有对应的可见表达，内嵌与无任务书不显示为「查无此包」
- [ ] 桌面与移动两个断点均可用，无横向溢出、无触控目标小于 44px
- [ ] 键盘可达、焦点环可见、对比度达 AA
- [ ] 双击 HTML 文件即可打开并正常工作，不依赖本地服务器
