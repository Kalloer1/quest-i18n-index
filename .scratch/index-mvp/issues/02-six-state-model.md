# 02: 数据集状态模型：六态入表

**What to build:**

让每一个被探测过的整合包都有明确、玩家看得懂的状态，而不是只有 57 条分成两态、其余 443 条凭空消失。

实测分布（`research/scan-cf500.tsv`，500 条）：无任务书 234、内嵌 104、无下载地址 85、
分离·单文件 43、超大未探测 18、分离·目录 14、其它 1、抓取失败 1。

六态词表（本轮定案，须同步进 `GLOSSARY.md`）：

| 状态 | 含义 |
|---|---|
| 可下载 | 本站已产出该整合包任务书汉化（本轮恒为 0，结构须留出） |
| 自带中文 | 整合包自身已带中文 |
| 待翻译·无人覆盖 | 有英文源，本站未翻，社区也没有 |
| 待翻译·社区已覆盖 | 有英文源，本站未翻，但 VM 或 CFPA 已有 |
| 内嵌不可做 | 任务书文本混在章节数据里，该版本 FTB Quests 无翻译系统 |
| 无任务书 | 不含 FTB Quests |

「超大未探测」与「抓取失败」是**探测未完成**，不是整合包属性，须与六态分开表达，不可混入。
