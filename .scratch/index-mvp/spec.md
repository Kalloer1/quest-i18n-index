# Spec: 索引 MVP（查 + 数据修正）

**状态：** approved
**日期：** 2026-10-17

## 目标

让玩家能查到一个整合包的任务书汉化状态，并知道汉化在哪、适配哪个版本、能不能和别家混装。
本站本轮**不产出任何译文**。

## 本轮范围

- **查**：输入整合包名 → 任务书状态 + 汉化在哪
- **数据修正**：VM 误配、状态词表、VM 状态与版本、缺失元数据
- **合规**：来源、许可、非商业声明页

## 明确不做

翻译、术语库、消歧、校验器、SNBT 解析、产出流水线、「求」按钮、账号系统、广告。

## 技术栈（已定）

自包含静态 HTML：内联 CSS，零构建，零 CDN，双击可开。
数据构建器用 Node 无依赖脚本，产出 JSON，页面读取。
两个断点：桌面 ≥1200px、移动 ≤480px，同一文件内媒体查询。

## 硬约束

1. 索引只放链接，**不重分发**任何第三方内容（绕开许可风险）。
2. 「本站产出」与「社区已有」必须视觉强分栏，不可混排成一张表。
3. 每条外部结论必须可追溯到来源链接与抓取时间。
4. 不能混装警告必须在详情页显式出现，不可折叠隐藏。
5. 内嵌布局包必须显示为「内嵌不可做」，不可静默隐藏、不可归入「待翻译」。
